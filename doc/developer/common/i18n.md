# Internationalization

German (`de`) is the source language and the only one under our control. Every other locale is
produced by translators on the [Transifex platform](https://www.transifex.com/organization/hitobito)
and pulled back into the repositories; the core and each translated wagon is its own Transifex
project, mapped in `.tx/config`.

## Rules

* **Only ever edit `de` locale files.** Never touch `en`, `fr`, `it`, and never the german variants
  `de_CH` / `de_DE` either — those come from Transifex and your changes would be overwritten.
* Add new keys to the german locale files only — `config/locales/{models,views}.de.yml` in the
  core, `config/locales/{models,views}.[name].de.yml` in a wagon. The other languages catch up
  through Transifex.
* Always provide both `one` and `other` plural keys in the german files, even when they are
  identical in German — other languages need the distinction.
* No user-facing string belongs in the code. Use `I18n.t` and the Rails view and model translation
  conventions, including for model and attribute names (`activerecord.models`,
  `activerecord.attributes`).
* If a customer wants to edit the german texts themselves, this happens through a german variant
  locale (`de_CH`, `de_DE`) configured as `application.german_variant` in the wagon's
  `config/settings.yml`; it is applied over `de` during the build.

## Transifex

The Transifex client is wrapped in rake tasks (in a wagon with the `app:` prefix):

```
rake tx:init      # create the Transifex base configuration for a wagon
rake tx:config    # register the german locale files (run after adding one)
rake tx:push      # upload the german sources
rake tx:pull      # fetch the translated files
```

Translations are pulled with `--mode sourceastranslation`, see
[ADR-010](../../architecture/adr/010_transifex-mit-mode-sourceastranslation.md).

What has to be set up when a wagon should be translated is described in
[Mehrsprachigkeit / I18n](../guidelines.md#mehrsprachigkeit--i18n) (German) and in the
[wagon instructions](../../architecture/wagons/README.md#instructions-create-wagon).
